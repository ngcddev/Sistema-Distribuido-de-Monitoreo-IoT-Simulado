Administración de mediciones

Altas, consultas y cambios de lecturas. Esta vista habla solo con el servicio de Mediciones.

El simulador ya crea lecturas con POST. El botón manual sirve para crear una desde aquí. PUT no agrega: reemplaza sensor, valor y unidad de la fila cuyo id escribiste. PATCH cambia solo el valor.

Crear, modificar y borrar piden el usuario y la contraseña de administración (el navegador las solicita al intentarlo); consultar es libre.
