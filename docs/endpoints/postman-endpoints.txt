POST /monitoreo/umbrales  (PUT usa el mismo)

========================================
 PRUEBA DE FALLA (tolerancia a fallos)
========================================

docker compose stop mediciones

GET  /mediciones                    -> 502 servicio no disponible
GET  /monitoreo/resumen-general     -> 503
GET  /health                        -> mediciones: "no disponible"
GET  /monitoreo/circuitos           -> circuito open tras 3 fallos

docker compose start mediciones     -> se recupera solo (half_open -> closed)

========================================
 ORDEN SUGERIDO DE PRUEBA
========================================

1. GET /health
2. GET /sensores
3. POST /mediciones  {"sensor_id":1,"valor":22.5,"unidad":"C"}
4. GET /monitoreo/1
5. POST /mediciones  {"sensor_id":1,"valor":50,"unidad":"C"}
6. GET /monitoreo/evaluar/1   -> debe dar ALERTA_CRITICA
7. GET /monitoreo/circuitos

========================================
 PREVIO: docker compose up -d --build
========================================
Todos los servicios deben estar corriendo.
Health individual de cada servicio (opcional, directo):
sensores    -> http://localhost:5003/health
mediciones  -> http://localhost:5001/health
monitoreo   -> http://localhost:5002/health
home        -> http://localhost:8080
simulador   -> genera mediciones cada 5s automaticamente
